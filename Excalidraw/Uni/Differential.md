جزوه اول با انتگرال گیری شروع شده و بعد مباحث معادلات دیفرانسیل و در آخر roadmap برای حل انواع سوال ها.
## **I. فرمول‌ها و قواعد اصلی انتگرال‌گیری**

### **۱. انتگرال توابع توانی (Power Rule)**

این قاعده اساسی‌ترین ابزار در حل معادلات دیفرانسیل تفکیک‌پذیر است:

$$\mathbf{\int x^n dx = \frac{x^{n+1}}{n+1} + C} \quad (\text{برای } n \neq -1)$$ [۱, ۲]

|مثال از جزوه/کاربرد در معادلات|حل|
|:--|:--|
|$\mathbf{\int x^r dx}$ [۱, ۲]|$\frac{x^{r+1}}{r+1} + C$ [۱, ۲]|
|$\mathbf{\int x dx}$ [۱, ۲]|$\frac{x^2}{2} + C$ [۱, ۲]|
|$\mathbf{\int x^{-2} dx}$ [۱, ۲]|$\frac{x^{-1}}{-1} + C = -\frac{1}{x} + C$ [۱, ۲]|
|$\mathbf{\int \sqrt{x} dx} = \int x^{\frac{1}{2}} dx$ [۱, ۲]|$\frac{x^{\frac{3}{2}}}{\frac{3}{2}} + C = \frac{2}{3} \sqrt{x^3} + C$ [۱, ۲]|

### **۲. انتگرال توابع نمایی و لگاریتمی (Exponential and Logarithmic)**

- **حالت نمایی:** $$\mathbf{\int e^{ax} dx = \frac{1}{a} e^{ax} + C}$$ [۱, ۲]
    - مثال: $\int e^{\frac{x}{\omega}} dx = \frac{1}{\frac{1}{\omega}} e^{\frac{x}{\omega}} + C = \omega e^{\frac{x}{\omega}} + C$ [۱, ۲].
- **حالت لگاریتمی (اهمیت بسیار بالا در عامل انتگرال‌ساز و جداسازی):** $$\mathbf{\int \frac{1}{x} dx = \ln|x| + C}$$ [۱, ۲] $$\mathbf{\int \frac{u'(x)}{u(x)} dx = \ln|u(x)| + C}$$ [۱, ۲]

### **۳. انتگرال توابع مثلثاتی (Trigonometric)**

| تابع                               | انتگرال (در جزوه ذکر شده)                   | کاربرد اصلی                               |
| :--------------------------------- | :------------------------------------------ | :---------------------------------------- |
| $\mathbf{\int \sin(ax) dx}$ [۱, ۲] | $\mathbf{-\frac{1}{a} \cos(ax) + C}$ [۱, ۲] | حل $y'' + \dots = \sin(ax)$               |
| $\mathbf{\int \cos(ax) dx}$ [۱, ۲] | $\mathbf{\frac{1}{a} \sin(ax) + C}$ [۱, ۲]  | حل $y'' + \dots = \cos(ax)$               |
| $\mathbf{\int \tan(x) dx}$ [۱, ۲]  | $\mathbf{-\ln                               | \cos x                                    |
| $\mathbf{\int \cot(x) dx}$ [۱, ۲]  | $\mathbf{\ln                                | \sin x                                    |
| $\mathbf{\int \sec(x) dx}$ [۱, ۲]  | $\mathbf{\ln                                | \sec x + \tan x                           |
| $\mathbf{\int \csc(x) dx}$ [۱, ۲]  | $\mathbf{-\ln                               | \csc x + \cot x                           |

| $\mathbf{\int \csc^2(x) dx}$ [۲۱]  | $\mathbf{-\cot x + C}$ [۲۱]                 | در حل معادله $y' - y\cot x = \csc x$ [۲۱] |

### **۴. انتگرال‌های خاص مورد نیاز:**

- **تابع معکوس مثلثاتی (Inverse Trigonometric):**
    - $\mathbf{\int \frac{dx}{1+x^2} = \arctan x + C}$ [۳۷, ۳۸].
    - $\mathbf{\int \frac{dx}{\sqrt{a^2 - x^2}} = \arcsin \frac{x}{a} + C}$ [۶۳, ۶۴].

## **II. روش تغییر متغیر (Substitution Method)**

تغییر متغیر (یا جایگزینی) مهم‌ترین روش برای تبدیل انتگرال‌های پیچیده به فرم‌های ساده‌تر است. این روش به ویژه در حل معادلات همگن [۴۳، ۴۴] و تفکیک‌پذیر کاربرد دارد.

**قاعده کلی:** اگر انتگرال $\int f(g(x)) g'(x) dx$ را داشته باشیم، با فرض $\mathbf{u = g(x)}$، آنگاه $\mathbf{du = g'(x) dx}$، و انتگرال به $\int f(u) du$ تبدیل می‌شود.

### **مثال ۱: انتگرال نمایی با تغییر متغیر (از جزوه)**

**انتگرال:** $\mathbf{\int \sin x e^{\cos x} dx}$ [۳, ۴]

**حل گام به گام:**

1. **انتخاب متغیر:** تابعی را انتخاب می‌کنیم که مشتقش نیز در عبارت وجود داشته باشد:
    - فرض می‌کنیم $\mathbf{w = \cos x}$ [۳, ۴].
2. **محاسبه دیفرانسیل:** از دو طرف مشتق می‌گیریم:
    - $\mathbf{dw = -\sin x dx}$ [۳, ۴].
    - بنابراین، $\mathbf{\sin x dx = -dw}$.
3. **جایگذاری و حل:**
    - $\int \sin x e^{\cos x} dx = \int e^w (-dw) = -\int e^w dw$ [۳, ۴].
    - حل انتگرال جدید: $-e^w + C$ [۳, ۴].
4. **بازگشت:** جایگزینی $w=\cos x$:
    - **جواب نهایی:** $\mathbf{-e^{\cos x} + C}$ [۳, ۴].

### **مثال ۲: انتگرال رادیکالی با تغییر متغیر (از جزوه)**

**انتگرال:** $\mathbf{\int x \sqrt{x^2+1} dx}$ [۳, ۴]

**حل گام به گام:**

1. **انتخاب متغیر:** فرض می‌کنیم $\mathbf{t = x^2 + 1}$ [۳, ۴].
2. **محاسبه دیفرانسیل:**
    - $dt = 2x dx$ [۳, ۴].
    - بنابراین، $\mathbf{x dx = \frac{1}{2} dt}$ [۳, ۴].
3. **جایگذاری و حل:**
    - $\int \sqrt{t} \left(\frac{1}{2} dt\right) = \frac{1}{2} \int t^{\frac{1}{2}} dt$ [۳, ۴].
    - با استفاده از قاعده توان: $\frac{1}{2} \left( \frac{t^{\frac{3}{2}}}{\frac{3}{2}} \right) + C = \frac{1}{2} \cdot \frac{2}{3} t^{\frac{3}{2}} + C = \frac{1}{3} t^{\frac{3}{2}} + C$ [۳, ۴].
4. **بازگشت:** جایگزینی $t = x^2+1$:
    - **جواب نهایی:** $\mathbf{\frac{1}{3} (x^2+1)^{\frac{3}{2}} + C}$ [۳, ۴].

### **مثال ۳: انتگرال لگاریتمی (در حل معادلات)**

**انتگرال:** $\mathbf{\int \frac{\ln x}{x} dx}$ [۳, ۴]

**حل گام به گام:**

1. **انتخاب متغیر:** $\mathbf{t = \ln x}$ [۳, ۴].
2. **محاسبه دیفرانسیل:** $\mathbf{dt = \frac{1}{x} dx}$ [۳, ۴].
3. **جایگذاری و حل:**
    - $\int t dt = \frac{1}{2} t^2 + C$ [۳, ۴].
4. **بازگشت:** $\mathbf{\frac{1}{2} (\ln x)^2 + C}$ [۳, ۴].

## **III. قواعد و کاربردهای مشتق‌گیری**

اگرچه تمرکز جزوه شما بر انتگرال است، اما مشتق‌گیری برای **تشکیل معادله دیفرانسیل** [۱۳, ۱۴] و **بررسی جواب‌ها** [۱۵, ۱۶] و **روش ضرایب نامعین** بسیار حیاتی است.

### **قواعد مشتق‌گیری کلیدی:**

1. **قاعده توان:** $\mathbf{\frac{d}{dx} (x^n) = n x^{n-1}}$.
2. **مشتق نمایی:** $\mathbf{\frac{d}{dx} (e^{ax}) = a e^{ax}}$ [۱۵, ۱۶].
3. **مشتق مثلثاتی:** $\mathbf{\frac{d}{dx} (\sin x) = \cos x}$ و $\mathbf{\frac{d}{dx} (\cos x) = -\sin x}$ [۱۵, ۱۶].

### **مثال کاربردی (تشکیل معادله دیفرانسیل):**

**مسئله:** معادله دیفرانسیل خانواده منحنی‌های $\mathbf{y = x^2 + C x + C}$ را تشکیل دهید [۱۵].

**حل گام به گام:**

1. **مشتق‌گیری (مرتبه ۱):** چون یک ثابت اختیاری ($C$) داریم، باید مشتق مرتبه اول را محاسبه کنیم [۱۵]:
    - $y' = 2x + C$ [۱۵].
2. **حذف ثابت $C$:** $C$ را از معادله $y'$ جدا می‌کنیم:
    - $\mathbf{C = y' - 2x}$ [۱۵].
3. **جایگذاری:** $C$ را در معادله اصلی جایگذاری می‌کنیم:
    - $y = x^2 + (y'-2x)x + (y'-2x)$ [۱۵].
    - $y = x^2 + x y' - 2x^2 + y' - 2x$ [۱۵].
4. **نظم دهی (معادله دیفرانسیل):**
    - $y' (x+1) + x^2 - 2x - y = 0$. (این معادله دیفرانسیل خانواده اصلی است.) [۱۵]

### **نکته کلیدی در حل معادلات:**

**هرگاه در معادلات دیفرانسیل نیاز به انتگرال‌گیری از یک کسر داشتید، ابتدا چک کنید که آیا صورت، مشتق مخرج است یا خیر.** اگر $\int \frac{u'}{u} dx$ بود، جواب فوراً $\ln|u| + C$ خواهد بود.

**مانند کلید اصلی برای حل انواع قفل‌ها، تسلط بر تغییر متغیر و انتگرال‌های لگاریتمی، ابزارهای اصلی شما برای حل تمام روش‌های معادله دیفرانسیل مرتبه اول (بخصوص خطی، برنولی، و تفکیک‌پذیر) خواهند بود.**

## **I. مفاهیم اولیه و تعاریف**

- **معادله دیفرانسیل**: رابطه‌ای که شامل یک متغیر مستقل ($x$)، یک متغیر وابسته ($y$) و مشتقات آن باشد.
    - **مرتبه (Order)**: بالاترین مرتبه مشتق موجود در معادله.
    - **درجه (Degree)**: (در منابع ذکر نشده است، اما جزو تعاریف اصلی است.)
- **انواع جواب**:
    - **جواب عمومی** ($y_c$): شامل ثابت‌های اختیاری ($C_1, C_2, \dots$) به تعداد مرتبه معادله.
    - **جواب خصوصی** ($y_p$): جوابی که ثابت‌های اختیاری آن با اعمال شرایط اولیه (مانند $y(x_0)=y_0$) تعیین شده‌اند.
- **تشکیل معادله دیفرانسیل**: حذف ثابت‌های اختیاری از یک خانواده منحنی‌ها برای رسیدن به معادله دیفرانسیل حاکم.
- **مسیرهای متعامد** (Orthogonal Trajectories): منحنی‌هایی که بر منحنی‌های خانواده اصلی در هر نقطه عمود هستند.

## **II. معادلات دیفرانسیل مرتبه اول**

معادلات به فرم $y' = f(x, y)$ یا $P(x, y) dx + Q(x, y) dy = 0$.

### **۱. معادلات تفکیک‌پذیر (Separable)**

- **روش حل:** جداسازی متغیرها به فرم $f(x) dx = g(y) dy$ و سپس انتگرال‌گیری از طرفین.

### **۲. معادلات خطی (Linear)**

- **فرمول استاندارد:** $\mathbf{y' + P(x)y = Q(x)}$.
- **روش حل:** استفاده از **عامل انتگرال‌ساز ($\mathbf{\mu}$)**:
    
    1. محاسبه $\mu (x) = e^{\int P(x) dx}$.
    2. جواب عمومی: $\mathbf{y = \frac{1}{\mu(x)} [\int \mu(x) Q(x) dx + C]}$.
    
    - **توجه:** اگر معادله نسبت به $x$ خطی باشد: $x' + p(y)x = q(y)$.

### **۳. معادلات برنولی (Bernoulli)**

- **فرمول استاندارد:** $\mathbf{y' + P(x)y = Q(x)y^n}$.
- **روش حل:** تبدیل به معادله خطی با استفاده از تغییر متغیر: $\mathbf{v = y^{1-n}}$.

### **۴. معادلات همگن (Homogeneous)**

- **تعریف:** معادلاتی که به صورت $\mathbf{y' = f(y/x)}$ قابل بیان هستند.
- **روش حل:** استفاده از تغییر متغیر: $\mathbf{v = y/x}$ (یا $\mathbf{y = vx}$) که منجر به یک معادله تفکیک‌پذیر می‌شود.

### **۵. معادلات تبدیل‌پذیر به همگن (Reducing to Homogeneous)**

- **فرم:** $y' = \phi(\frac{ax+by+c}{a'x+b'y+c'})$.
- **روش حل:**
    - **حالت ۱:** خطوط موازی ($\frac{a}{a'} = \frac{b}{b'}$): تغییر متغیر $\mathbf{u = ax+by}$.
    - **حالت ۲:** خطوط متقاطع (یا $c=c'=0$): انتقال دستگاه مختصات با پیدا کردن نقطه تقاطع ($\alpha, \beta$) و استفاده از $\mathbf{x=X+\alpha}, \mathbf{y=Y+\beta}$.

### **۶. معادلات کامل (Exact)**

- **فرمول استاندارد:** $P(x, y) dx + Q(x, y) dy = 0$.
- **شرط کمال:** $\mathbf{\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}}$.
- **روش حل:** پیدا کردن تابع $\psi(x, y)$ به طوری که $\mathbf{\psi(x, y) = C}$ جواب باشد:
    1. $\psi(x, y) = \int P(x, y) dx + k(y)$.
    2. $\frac{\partial \psi}{\partial y} = Q(x, y)$ (برای یافتن $k(y)$).

### **۷. عامل انتگرال‌ساز (Integrating Factor)**

- **کاربرد:** برای تبدیل معادلات غیرکامل به کامل.
- **روش‌های اصلی (در منابع ذکر شده):**
    - اگر $\frac{P_y - Q_x}{Q}$ فقط تابعی از $x$ باشد، عامل انتگرال‌ساز $\mathbf{\mu(x) = e^{\int \frac{P_y - Q_x}{Q} dx}}$ است.
    - اگر $\frac{Q_x - P_y}{P}$ فقط تابعی از $y$ باشد، عامل انتگرال‌ساز $\mathbf{\mu(y) = e^{\int \frac{Q_x - P_y}{P} dy}}$ است.
    - حالات خاص عامل انتگرال‌ساز همگن (فرم $\mu(x, y) = x^{\alpha} y^{\beta}$).

## **III. معادلات دیفرانسیل مرتبه بالا**

### **۱. معادلات با حذف متغیر (Reduction of Order)**

- **حالت ۱: $y$ غایب است** ($F(x, y', y'') = 0$):
    - تغییر متغیر: $\mathbf{u = y'}$, در نتیجه $\mathbf{u' = y''}$.
- **حالت ۲: $x$ غایب است** ($F(y, y', y'') = 0$):
    - تغییر متغیر: $\mathbf{u = y'}$، در نتیجه $\mathbf{y'' = u \frac{du}{dy}}$.

### **۲. معادلات خطی همگن با ضرایب ثابت**

- **فرمول استاندارد:** $y^{(n)} + a_{n-1} y^{(n-1)} + \dots + a_1 y' + a_0 y = 0$.
- **روش حل:** تشکیل **معادله مشخصه (Characteristic Equation)**: $r^n + a_{n-1} r^{n-1} + \dots + a_0 = 0$.
- **انواع ریشه‌ها و جواب عمومی $\mathbf{y_c}$:**
    - **ریشه‌های حقیقی متمایز ($r_1 \neq r_2$):** $y_c = c_1 e^{r_1 x} + c_2 e^{r_2 x} + \dots$.
    - **ریشه‌های حقیقی تکراری ($r_1 = r_2$):** $y_c = c_1 e^{r x} + c_2 x e^{r x} + \dots$.
    - **ریشه‌های مختلط مزدوج ($\mathbf{r = \alpha \pm i\beta}$):** $\mathbf{y_c = e^{\alpha x} (c_1 \cos(\beta x) + c_2 \sin(\beta x))}$.

### **۳. معادلات خطی ناهمگن با ضرایب ثابت**

- **فرمول استاندارد:** $y^{(n)} + \dots + a_0 y = g(x)$.
    
- **جواب کلی:** $\mathbf{y = y_c + y_p}$ (جواب همگن + جواب خصوصی).
    
- **روش‌های یافتن $\mathbf{y_p}$:**
    
    #### **الف) روش ضرایب نامعین (Undetermined Coefficients)**
    
    - **کاربرد:** زمانی که $g(x)$ شامل چندجمله‌ای، نمایی، سینوس یا کسینوس باشد.
    - **فرم حدس $\mathbf{y_p}$ (بر اساس $\mathbf{g(x)}$):**
        - چندجمله‌ای $\mathbf{P_m(x)}$: $\mathbf{y_p = x^s P_{m}(x)}$.
        - نمایی $\mathbf{e^{ax}}$: $\mathbf{y_p = x^s A e^{ax}}$.
        - سینوس یا کسینوس: $\mathbf{y_p = x^s e^{\alpha x} (A \cos(\beta x) + B \sin(\beta x))}$.
    - **$s$ (تعداد تکرار):** تعداد دفعاتی که ریشه مربوط به $g(x)$ در معادله مشخصه $y_c$ تکرار شده است.
    
    #### **ب) روش تغییر پارامترها (Variation of Parameters)**
    
    - **کاربرد:** برای هر نوع تابع $g(x)$ قابل استفاده است.
    - **مراحل:**
        1. یافتن $y_c = c_1 y_1 + c_2 y_2$.
        2. محاسبه **ورونسکین (Wronskian)** $\mathbf{W = \det (y_i, y'_i)}$.
        3. محاسبه $W_1$ و $W_2$ (با جایگزینی ستون اول و دوم ورونسکین با $[0, g(x)]$ یا $[0, g(x)/a_n]$).
        4. $\mathbf{y_p = y_1 \int \frac{W_1}{W} dx + y_2 \int \frac{W_2}{W} dx}$.

### **۴. معادلات کوشی-اویلر (Cauchy-Euler) و خطی عمومی**

- **فرمول استاندارد کوشی-اویلر (همگن):** $\mathbf{x^n y^{(n)} + \dots + a_1 x y' + a_0 y = g(x)}$.
- **روش حل:** استفاده از تغییر متغیر: $\mathbf{x = e^z}$ یا $\mathbf{z = \ln x}$.
    - این تغییر، معادله را به یک معادله خطی با **ضرایب ثابت** بر حسب متغیر $z$ تبدیل می‌کند.
- **معادلات خطی عمومی:** فرم $(ax+b)^n y^{(n)} + \dots = g(x)$.
    - روش حل: تغییر متغیر $\mathbf{t = ax+b}$.

> **تشبیه مفهومی:** اگر معادلات دیفرانسیل را به یک **قفل پیچیده** تشبیه کنیم، **مرتبه معادله** همان تعداد لایه‌های محافظ قفل است. **معادله مشخصه** (برای ضرایب ثابت) مانند پیدا کردن کُد اصلی قفل است، و **روش‌های مختلف حل** (تفکیک‌پذیر، همگن، ضرایب نامعین و...) هر کدام کلیدهای تخصصی هستند که برای باز کردن انواع مختلف آن قفل‌ها (معادلات) طراحی شده‌اند. برای موفقیت در میان‌ترم، کافی است هر کلید را در جای درست خودش امتحان کنید.


# I. معادلات دیفرانسیل مرتبه اول

## ۱. معادلات تفکیک‌پذیر (Separable Equations)

این معادلات به فرم $y' = f(x)g(y)$ هستند یا می‌توانند با تغییر متغیر به این فرم درآیند.

### **نقشه راه حل:**

1. **جداسازی:** معادله را به فرم $P(x) dx + Q(y) dy = 0$ (یا $\frac{dy}{g(y)} = f(x) dx$) تبدیل کنید.
2. **انتگرال‌گیری:** از طرفین معادله نسبت به متغیر مربوطه انتگرال بگیرید.
3. **جواب عمومی:** ثابت انتگرال (C) را اضافه کرده و در صورت امکان، جواب $y$ را به صورت صریح بر حسب $x$ به دست آورید.

### **مثال حل شده (تبدیل به تفکیک‌پذیر):**

**معادله:** $y' = \tan^2(x+y)$

**حل گام به گام:**

1. **تغییر متغیر:** تغییر متغیر $\mathbf{v = x+y}$ را اعمال می‌کنیم.
    - در نتیجه: $v' = 1 + y'$.
    - پس: $\mathbf{y' = v' - 1}$.
2. **تبدیل معادله:** جایگذاری در معادله اصلی:
    - $v' - 1 = \tan^2(v)$.
    - $v' = 1 + \tan^2(v)$.
    - با استفاده از اتحاد مثلثاتی $1 + \tan^2(v) = \sec^2(v)$: $\mathbf{v' = \sec^2(v)}$.
3. **جداسازی و انتگرال‌گیری:** معادله بر حسب $v$ و $x$ تفکیک‌پذیر است:
    - $\frac{dv}{\sec^2(v)} = dx$.
    - $\cos^2(v) dv = dx$. (این مرحله در جزوه حل نشده است، اما جزو مراحل استاندارد است.)
    - در مثالی دیگر در جزوه، از جداسازی $\frac{dv}{\tan^2(v)+1} = dx$ استفاده شده است.
    - در مثالی دیگر برای $y'=\tan(x+y)$, جداسازی به صورت $\frac{dv}{\tan v} = dx$ و انتگرال‌گیری منجر به $\int \cot v dv = \int dx$ و در نهایت $\ln|\sin v| = x + C$ شده است.
4. **بازگشت به متغیر اصلی:** با جایگذاری $v=x+y$، جواب نهایی به دست می‌آید: $\mathbf{\ln|\sin(x+y)| = x + C}$.

---

## ۲. معادلات خطی مرتبه اول (Linear First Order ODEs)

این معادلات به فرم استاندارد $\mathbf{y' + P(x)y = Q(x)}$ هستند.

### **نقشه راه حل:**

1. **فرم استاندارد:** معادله را به فرم $y' + p(x)y = g(x)$ مرتب کنید.
2. **محاسبه عامل انتگرال‌ساز ($\mu$):** عامل انتگرال‌ساز را با استفاده از فرمول $\mathbf{\mu(x) = e^{\int p(x) dx}}$ محاسبه کنید.
3. **محاسبه جواب عمومی:** جواب عمومی را مستقیماً از فرمول به دست آورید: $$\mathbf{y(x) = \frac{1}{\mu(x)} [\int \mu(x) g(x) dx + C]}$$.

### **مثال حل شده:**

**معادله:** $y' - y\cot x = \csc x$

**حل گام به گام:**

1. **فرم استاندارد:** معادله در فرم استاندارد است.
    - $p(x) = -\cot x$.
    - $g(x) = \csc x$.
2. **محاسبه عامل انتگرال‌ساز:**
    - $\mu(x) = e^{\int p(x) dx} = e^{\int -\cot x dx}$.
    - $\int -\cot x dx = -\ln|\sin x| = \ln|(\sin x)^{-1}| = \ln|\csc x|$. (زیرا $\cot x = \frac{\cos x}{\sin x}$)
    - $\mathbf{\mu(x)} = e^{\ln|\csc x|} = \mathbf{\csc x} = \frac{1}{\sin x}$.
3. **محاسبه جواب عمومی:**
    - $y = \frac{1}{\mu} \left[\int \mu g(x) dx + C\right]$.
    - $y = \frac{1}{\csc x} \left[\int \csc x \cdot \csc x dx + C\right]$.
    - $y = \sin x \left[\int \csc^2 x dx + C\right]$.
    - از آنجایی که $\int \csc^2 x dx = -\cot x$:
    - $y = \sin x [-\cot x + C]$.
    - $y = \sin x \left[-\frac{\cos x}{\sin x} + C\right] \implies \mathbf{y = -\cos x + C \sin x}$.

---

## ۳. معادلات برنولی (Bernoulli Equations)

این معادلات به فرم $\mathbf{y' + P(x)y = Q(x)y^n}$ هستند، که در آن $n \neq 0$ و $n \neq 1$.

### **نقشه راه حل:**

1. **تغییر متغیر:** از تغییر متغیر $\mathbf{v = y^{1-n}}$ استفاده کنید.
2. **مشتق‌گیری:** مشتق $v'$ را بر حسب $y'$ و $y$ محاسبه کنید. در این حالت، $\mathbf{y' = \frac{1}{1-n} y^n v'}$.
3. **تبدیل به معادله خطی:** با جایگذاری $v$ و $y'$، معادله را به فرم خطی استاندارد (بر حسب $v$ و $x$) تبدیل کنید.
4. **حل معادله خطی:** از روش عامل انتگرال‌ساز برای یافتن $v(x)$ استفاده کنید.
5. **بازگشت:** با جایگذاری $y = v^{1/(1-n)}$ به متغیر اصلی بازگردید.

### **مثال حل شده:**

**معادله:** $y' + \frac{1}{x}y = x y^3$ (در این حالت $n=3$, $P(x)=1/x$, $Q(x)=x$)

**حل گام به گام:**

1. **تغییر متغیر:** $\mathbf{v = y^{1-3} = y^{-2}}$.
    - $y = v^{-1/2} \implies y' = -\frac{1}{2} v^{-3/2} v'$ (نیاز نیست، اما برای درک فرآیند تبدیل ضروری است).
    - با ضرب کل معادله در $(1-n) y^{-n} = -2 y^{-3}$، به فرم خطی می‌رسیم:
    - $-2 y^{-3} y' - 2 x^{-1} y^{-2} = -2 x$.
    - از آنجایی که $v = y^{-2}$، پس $v' = -2 y^{-3} y'$.
    - **معادله خطی:** $\mathbf{v' - \frac{2}{x} v = -2x}$.
2. **محاسبه عامل انتگرال‌ساز (برای $v$):** $p(x) = -2/x$.
    - $\mu(x) = e^{\int -2/x dx} = e^{-2 \ln x} = e^{\ln x^{-2}} = \mathbf{x^{-2}}$.
3. **حل برای $v$:**
    - $v = \frac{1}{\mu} \left[ \int \mu g(x) dx + C \right]$.
    - $v = x^2 \left[ \int x^{-2} (-2x) dx + C \right]$.
    - $v = x^2 \left[ \int -2 x^{-1} dx + C \right]$.
    - $v = x^2 \left[ -2 \ln|x| + C \right] = -2 x^2 \ln|x| + C x^2$.
4. **بازگشت به $y$:** از آنجایی که $v = y^{-2}$، پس $\mathbf{y = \frac{1}{\sqrt{v}}}$ (با فرض $y>0$):
    - $\mathbf{y^2 = \frac{1}{C x^2 - 2 x^2 \ln|x|}}$. (توجه: در جزوه جواب نهایی به صورت $y^2 = \frac{1}{x^2 (C - 2 \ln|x|)}$ نمایش داده شده است.)

## ۴. معادلات کامل و عامل انتگرال‌ساز (Exact ODEs and Integrating Factor)

معادلات به فرم $\mathbf{P(x, y) dx + Q(x, y) dy = 0}$.

### **نقشه راه حل (معادلات کامل):**

1. **بررسی شرط کمال:** شرط کمال $\mathbf{\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}}$ را بررسی کنید.
2. **انتگرال‌گیری جزئی:** اگر شرط برقرار بود، تابع جواب $\psi(x, y)$ را به یکی از دو روش زیر پیدا کنید:
    - $\psi(x, y) = \int P(x, y) dx + h(y)$ (گام ۱)
    - $\psi(x, y) = \int Q(x, y) dy + k(x)$ (گام ۱)
3. **یافتن تابع مجهول:** با مشتق‌گیری جزئی از تابع $\psi$ به دست آمده (مثلاً مشتق $\psi$ نسبت به $y$ در حالت اول) و برابر قرار دادن آن با تابع دیگر (مثلاً $Q(x, y)$)، تابع مجهول ($h(y)$ یا $k(x)$) را بیابید.
4. **جواب نهایی:** جواب عمومی به صورت $\mathbf{\psi(x, y) = C}$ است.

### **مثال حل شده (معادله کامل):**

**معادله:** $(\cos y) dx + (-x \sin y - y^2) dy = 0$

- $P(x, y) = \cos y$
- $Q(x, y) = -x \sin y - y^2$

**حل گام به گام:**

1. **بررسی کمال:**
    - $P_y = \frac{\partial}{\partial y} (\cos y) = \mathbf{-\sin y}$.
    - $Q_x = \frac{\partial}{\partial x} (-x \sin y - y^2) = \mathbf{-\sin y}$.
    - چون $P_y = Q_x$، معادله کامل است.
2. **یافتن $\psi(x, y)$ (با استفاده از $P$):**
    - $\psi(x, y) = \int P(x, y) dx + h(y) = \int (\cos y) dx + h(y)$.
    - $\psi(x, y) = \mathbf{x \cos y + h(y)}$.
3. **یافتن $h(y)$:** از $\psi$ نسبت به $y$ مشتق می‌گیریم و برابر $Q$ قرار می‌دهیم:
    - $\frac{\partial \psi}{\partial y} = -x \sin y + h'(y) = Q(x, y) = -x \sin y - y^2$.
    - نتیجه: $h'(y) = -y^2$.
    - انتگرال‌گیری از $h'(y)$: $h(y) = \int -y^2 dy = \mathbf{-\frac{1}{3} y^3 + C_1}$. (در جزوه به صورت $-\frac{1}{3} y^3 + C_1$ نشان داده شده است.)
4. **جواب نهایی:** با جایگذاری $h(y)$ در $\psi$:
    - $\psi(x, y) = x \cos y - \frac{1}{3} y^3 + C_1$.
    - **جواب عمومی:** $\mathbf{x \cos y - \frac{1}{3} y^3 = C}$.

---

## ۵. معادلات مسیرهای متعامد (Orthogonal Trajectories)

### **نقشه راه حل:**

1. **تشکیل معادله دیفرانسیل خانواده اصلی:** اگر خانواده منحنی‌ها به صورت $F(x, y, C) = 0$ داده شده، با مشتق‌گیری نسبت به $x$ و حذف $C$، معادله دیفرانسیل اصلی $y' = f(x, y)$ را به دست آورید.
2. **تبدیل برای منحنی‌های متعامد:** شیب را برای مسیرهای متعامد با استفاده از رابطه $\mathbf{y'_{\perp} = -\frac{1}{f(x, y)}}$ جایگزین کنید.
3. **حل معادله جدید:** معادله دیفرانسیل جدید مرتبه اول (که عموماً تفکیک‌پذیر یا خطی است) را حل کنید.

### **مثال حل شده:**

**خانواده منحنی‌ها:** خانواده دایره‌های متحدالمرکز $\mathbf{x^2 + y^2 = C^2}$.

**حل گام به گام:**

1. **حذف ثابت $C$:**
    - از $x^2 + y^2 = C^2$ نسبت به $x$ مشتق می‌گیریم:
    - $2x + 2y y' = 0 \implies \mathbf{y' = -\frac{x}{y}}$. (این معادله دیفرانسیل خانواده دایره‌ها است.)
2. **تشکیل معادله متعامد:** $y'$ را با $-\frac{1}{y'}$ جایگزین می‌کنیم:
    - $\mathbf{y'_{\perp}} = -\frac{1}{(-\frac{x}{y})} = \mathbf{\frac{y}{x}}$.
3. **حل معادله متعامد (تفکیک‌پذیر):**
    - $\frac{dy}{dx} = \frac{y}{x} \implies \frac{dy}{y} = \frac{dx}{x}$.
    - انتگرال‌گیری: $\int \frac{dy}{y} = \int \frac{dx}{x} \implies \ln|y| = \ln|x| + C_1$.
    - $\ln|y| = \ln|x| + \ln|C| \implies \ln|y| = \ln|C x|$.
    - **جواب عمومی (خانواده خطوط متعامد):** $\mathbf{y = C x}$.
    - (این جواب خانواده خطوطی است که از مرکز دایره‌ها می‌گذرند و بر دایره‌ها عمودند.)

# II. معادلات دیفرانسیل مرتبه بالا (ضرایب ثابت و کوشی-اویلر)

## ۶. معادلات خطی همگن با ضرایب ثابت

معادلات به فرم $\mathbf{a y'' + b y' + c y = 0}$.

### **نقشه راه حل:**

1. **معادله مشخصه:** معادله مشخصه را با جایگزینی $y=e^{rx}$ به دست آورید: $\mathbf{a r^2 + b r + c = 0}$.
2. **یافتن ریشه‌ها:** ریشه‌های $r$ را از معادله درجه دوم پیدا کنید.
3. **تشکیل جواب عمومی ($y_c$):**
    - **ریشه‌های حقیقی متمایز ($r_1 \neq r_2$):** $\mathbf{y_c = C_1 e^{r_1 x} + C_2 e^{r_2 x}}$.
    - **ریشه‌های حقیقی تکراری ($r_1 = r_2$):** $\mathbf{y_c = C_1 e^{r x} + C_2 x e^{r x}}$.
    - **ریشه‌های مختلط مزدوج ($r = \alpha \pm i \beta$):** $\mathbf{y_c = e^{\alpha x} (C_1 \cos(\beta x) + C_2 \sin(\beta x))}$.

### **مثال حل شده (ریشه‌های مختلط):**

**معادله:** $y'' + 4y' + 13y = 0$ (در جزوه مثال‌های مشابهی برای این حالت حل شده است.)

**حل گام به گام:**

1. **معادله مشخصه:** $r^2 + 4r + 13 = 0$ [بر اساس روش‌های ۹۱].
2. **یافتن ریشه‌ها:** با استفاده از $\Delta = b^2 - 4ac$:
    - $\Delta = 4^2 - 4(1)(13) = 16 - 52 = -36$ [بر اساس روش‌های ۹۱].
    - $r = \frac{-4 \pm \sqrt{-36}}{2} = \frac{-4 \pm 6i}{2} = \mathbf{-2 \pm 3i}$.
3. **جواب عمومی:** ریشه‌ها مختلط هستند با $\alpha = -2$ و $\beta = 3$.
    - $\mathbf{y(x) = e^{-2x} (C_1 \cos(3x) + C_2 \sin(3x))}$.

---

## ۷. معادلات خطی ناهمگن (روش ضرایب نامعین)

معادلات به فرم $\mathbf{a y'' + b y' + c y = g(x)}$ که در آن $g(x)$ تابعی از چندجمله‌ای، نمایی یا مثلثاتی است.

### **نقشه راه حل:**

1. **حل معادله همگن ($y_c$):** با استفاده از روش ریشه‌های معادله مشخصه (مرحله ۶)، $y_c$ را بیابید.
2. **حدس جواب خصوصی ($y_p$):** بر اساس شکل تابع $g(x)$، شکل $y_p$ را حدس بزنید (شامل ضرایب نامعین $A, B, \dots$).
    - **قاعده اصلاح (Modification Rule):** اگر هر جزء از $y_p$ در $y_c$ تکرار شده باشد، $y_p$ را در $x^s$ ضرب کنید، که $s$ کوچکترین عدد صحیح نامنفی برای جلوگیری از تکرار است.
3. **یافتن ضرایب:** $y_p$ و مشتقاتش را در معادله ناهمگن اصلی جایگذاری کنید و ضرایب نامعین را با حل دستگاه معادلات به دست آورید.
4. **جواب نهایی:** $\mathbf{y = y_c + y_p}$.

### **مثال حل شده (چندجمله‌ای):**

**معادله:** $y'' + y = x^2 + 1$

**حل گام به گام:**

1. **حل همگن ($y_c$):**
    - معادله مشخصه: $r^2 + 1 = 0 \implies r = \pm i$.
    - $\alpha = 0, \beta = 1$.
    - $y_c = C_1 \cos x + C_2 \sin x$.
2. **حدس جواب خصوصی ($y_p$):**
    - $g(x) = x^2 + 1$ (چندجمله‌ای درجه ۲).
    - حدس اولیه: $y_p = A x^2 + B x + C$.
    - چون هیچ جزء تکراری با $y_c$ وجود ندارد، $\mathbf{s=0}$.
    - $y_p = A x^2 + B x + C$.
3. **محاسبه مشتقات و جایگذاری:**
    - $y'_p = 2 A x + B$.
    - $y''_p = 2 A$.
    - جایگذاری در $y'' + y = x^2 + 1$:
    - $(2A) + (A x^2 + B x + C) = x^2 + 1$.
    - $A x^2 + B x + (2A + C) = 1 x^2 + 0 x + 1$.
    - با برابر قرار دادن ضرایب:
        - $x^2: A = 1$.
        - $x: B = 0$.
        - ثابت: $2A + C = 1 \implies 2(1) + C = 1 \implies C = -1$.
    - **جواب خصوصی:** $\mathbf{y_p = x^2 - 1}$.
4. **جواب نهایی:**
    - $\mathbf{y = C_1 \cos x + C_2 \sin x + x^2 - 1}$.

---

## ۸. معادلات کوشی-اویلر (Cauchy-Euler Equations)

معادلاتی به فرم $\mathbf{a x^n y^{(n)} + \dots + a_1 x y' + a_0 y = g(x)}$.

### **نقشه راه حل:**

1. **تغییر متغیر:** از تغییر متغیر $\mathbf{x = e^z}$ (یا $\mathbf{z = \ln x}$) استفاده کنید.
2. **تبدیل مشتقات:** از روابط تبدیل زیر استفاده کنید تا معادله اصلی به معادله خطی با ضرایب ثابت (بر حسب $z$) تبدیل شود:
    - $x \frac{dy}{dx} = \frac{dy}{dz}$
    - $x^2 \frac{d^2 y}{dx^2} = \frac{d^2 y}{dz^2} - \frac{dy}{dz}$
3. **حل معادله جدید ($y(z)$):** معادله را بر حسب $z$ با استفاده از روش ریشه‌های مشخصه (برای $y_c$) و ضرایب نامعین یا تغییر پارامتر (برای $y_p$) حل کنید.
4. **بازگشت به $x$:** با جایگذاری $z = \ln x$ به متغیر اصلی بازگردید.

### **مثال حل شده:**

**معادله:** $x^2 y'' + x y' - y = x^2$ ($x>0$)

**حل گام به گام:**

1. **تبدیل به معادله ضرایب ثابت (متغیر $z$):**
    
    - با اعمال تبدیلات $x^2 y'' \to y''_{zz} - y'_{z}$ و $x y' \to y'_{z}$ و $x^2 \to (e^z)^2 = e^{2z}$:
    - $(y''_{zz} - y'_{z}) + (y'_{z}) - y = e^{2z}$.
    - **معادله جدید:** $\mathbf{y'' - y = e^{2z}}$.
2. **حل قسمت همگن ($y_c$):**
    
    - معادله مشخصه: $r^2 - 1 = 0 \implies r = \pm 1$.
    - $y_c(z) = C_1 e^z + C_2 e^{-z}$.
3. **حل قسمت خصوصی ($y_p$):** (روش ضرایب نامعین)
    
    - $g(z) = e^{2z}$. ریشه مربوطه $r=2$. ریشه ۲ در $y_c$ تکرار نشده است، پس $\mathbf{s=0}$.
    - حدس: $y_p = A e^{2z}$.
    - $y'_p = 2 A e^{2z}$, $y''_p = 4 A e^{2z}$.
    - جایگذاری در $y'' - y = e^{2z}$:
    - $4 A e^{2z} - A e^{2z} = e^{2z}$.
    - $3 A e^{2z} = 1 e^{2z} \implies A = 1/3$.
    - $y_p(z) = \frac{1}{3} e^{2z}$.
4. **جواب نهایی و بازگشت به $x$:**
    
    - $y(z) = y_c + y_p = C_1 e^z + C_2 e^{-z} + \frac{1}{3} e^{2z}$.
    - با جایگذاری $z = \ln x$ و استفاده از $e^z = x$ و $e^{-z} = 1/x$ و $e^{2z} = x^2$:
    - **جواب عمومی:** $\mathbf{y(x) = C_1 x + \frac{C_2}{x} + \frac{1}{3} x^2}$.
