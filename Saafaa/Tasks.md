1) رو سیستم خودتون دو تا داکر رو باید بیارید بالا(ترجیحا با داکر کامپوز). یکی geoserver (نسخه kartoza) و یکی postgresql . البته میخوام روی postgresql حتما اکستنشن postgis نصب باشه( در مورد postgis یه سرچ کوچیک بکنید که چیه فقط)
2) یه دیتابیس توی posgresql بسازید به اسم mydata 
3) یه فایل sql الان براتون میفرستم که باید ایمپورت کنید توی دیتابیسی که ساختید
4) توی جئوسرور یه workspace جدید بسازید به  اسم myworkspace
5) توی workspace یه store از نوع PostGIS  بسازید و متصل بشید به دیتابیسی که ساختید
6) جدولی که با استفاده از sql توی دیتابیس ایجاد شده بود رو توی جئوسرور تحت عنوان یک لایه جدید اضافه کنید(اصطلاحا publish کنید)
7) عنوان لایه رو بذارید ساختمان
8) تنظیمات bbox لایه رو انجام بدید
9) یک کارتوگرافی پیشفرض (از بین کارتوگرافی های پیشفرض جئوسرور) برای لایه انتخاب کنید
10) یک پیش نمایش از لایه رو ببینید و چک کنید که لایه رو روی نقشه توی جئوسرور نشون بده
11) یک فیلد به جدول ایجاد شده توی دیتابیس اضافه کنید به اسم  code و این فیلد رو برای چند تا از رکورد های جدول پر کنید
12) توی جئوسرور لایه رو بروزرسانی کنید که فیلد جدید رو بشناسه و توی لیست فیلد هاش بیاره
13) یک کارتوگرافی جدید از نوع پلیگونی بسازید که لیبل داشته باشه و مقدار code رو روی عارضه ها نشون بده
14) این کارتوگرافی رو به عنوان کارتوگرافی پیشفرض لایه تنظیم کنید و توی پیش نمایش لایه چک کنید که این کارتوگرافی رو به درستی نشون میده یا نه
15) با استفاده از لینک های wms و wfs لایه ساخته شده رو توی qgis اضافه کنید. چک کنید که با کارتوگرافی ساخته شده نشون داده بشه. یک عارضه اضافه، ویرایش و حذف کنید و چک کنید که توی دیتابیس این تغییرات اعمال بشن.
16) کش رو روی لایه فعال کنید. از زوم 1 تا 15 رو به وسیله جئوسرور کش کنید و چک کنید آیا این عملیات انجام شده یا نه.(بر اساس حجم کش لایه)
